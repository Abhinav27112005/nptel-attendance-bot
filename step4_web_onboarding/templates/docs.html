NPTEL Attendance Bot

A WhatsApp bot that fills your daily NPTEL internship attendance form in seconds.

Simple docs — samajhne ke liye, koi bhaari technical bhasha nahi. Har cheez seedhi tarah.

📌 Overview

Problem: NPTEL Summer Internship mein roz ek Google Form bharni padti hai — 12 fields, jinme sirf "aaj kya kaam kiya" aur time badalta hai, baaki sab same. Boring, repetitive.

Solution: Ek WhatsApp bot ko bhejo WORK: aaj jo kaam kiya → woh ek bhara-bharaya form link wapas bhejta hai. Tum tap karke Submit dabao — ho gaya.

✅
Result: 2 minute ka manual kaam → 10 second ka WhatsApp message. 10 doston ke liye ek saath kaam karta hai.

⚙️ How it works

3 alag hisse (components), 3 alag jagah host:

1
WhatsApp Bot (Node.js)
Phone / Termux · sunta & jawab deta
2
Website + Admin Panel (Python Flask)
Render · registration & dashboard
3
Database (MongoDB Atlas)
Cloud · dono share karte hain
4
PDF Storage (Cloudinary)
Cloud · offer letters

Data flow — attendance kaise banti hai

  1. Tum WhatsApp pe bhejo: WORK: aaj data cleaning kiya
  2. Bot DB se tumhara profile utha ke summary dikhata hai (naam, ID, time, kaam)
  3. Tum YES bhejo
  4. Bot pre-filled Google Form URL banata hai (saare entry IDs ke saath), usse short link banata hai (30 min valid)
  5. Short link WhatsApp pe aata hai → tum tap karo → form tumhare phone pe, tumhare Gmail se khulta hai, sab bhara hua
  6. Tum Submit dabao → attendance lag gayi
💡
Clever part: Bot khud form submit nahi karta — link bhejta hai jo tumhare phone pe khulta hai. Isliye tumhara apna Gmail use hota hai, aur server pe bhaari browser automation nahi chahiye.

🧰 Tech stack — aur kyun

whatsapp-web.js ›

WhatsApp automation library. Ek chhupe hue browser (Puppeteer) mein WhatsApp Web chalata hai. Free — WhatsApp Business API ki zaroorat nahi. Trade-off: QR scan chahiye, thoda kam stable.

Pre-filled URL (Playwright ki jagah) ›

Pehle Playwright se server pe Chrome khol ke form bharte the. Baad mein switch kiya pre-filled Google Form link pe — form user ke apne phone pe khulta hai, unke Gmail se. Isse Gmail ka issue solve hua aur hosting sasti ho gayi.

pdfplumber + regex (Claude API ki jagah) ›

Offer letter ka format fixed hai, isliye free regex se details nikal lete hain. Claude API paisa leta — yahan zaroorat nahi thi.

Flask ›

Chhota Python web framework — 2-3 routes ke liye perfect (registration, admin, short-link redirect).

MongoDB Atlas ›

Document database — profile data JSON jaisा fit hota hai. Free 512MB. Node aur Python dono se easily connect hota hai.

Cloudinary ›

Free file storage (25GB). Render ka filesystem restart pe udd jata hai, isliye PDFs Cloudinary pe rakhte hain — permanent URL milta hai.

📂 Code explained (aasaan bhasa)

Project 3 folders mein banta hai:

step2_whatsapp_bot/ — the bot ›

bot.js

Dil hai project ka. Kaam:

  • Event listeners — WhatsApp message aate hi react karta hai (doorbell jaisा).
  • State machine — har user ka ek "state" hota hai: IDLE (koi kaam nahi) ya AWAITING_CONFIRM (YES ka wait). ATM machine jaisा — har state mein alag behave.
  • Command parsing — sirf ye commands react karte hain: REGISTER, LINK, WORK:, YES, CANCEL, LOGIN, !status, !help. Baaki sab ignore (privacy).
  • Auth strategy — MongoDB ya local disk pe WhatsApp session save karta hai (taaki dobara QR na scan karna pade).
  • Health server — ek chhota webpage (/qr, /health) jo QR dikhata hai aur "bot zinda hai" batata hai.

prefill.js

Google Form ka bhara-bharaya URL banata hai. Har field ka ek entry.XXXX ID hota hai (form inspect karke nikale the). Ye un IDs ke saath URL jodta hai.

db.js

Data layer. Users ko MongoDB se laata/save karta hai. Smart: agar cloud set hai to MongoDB, warna local files — same code dono pe.

reminder.js

Cron scheduler. Shaam 5-11 baje har 30 min un logon ko reminder bhejta hai jinhone aaj attendance nahi bhari.

step4_web_onboarding/ — the website ›

app.py

Flask server. Routes: / (registration), /register (PDF upload process), /r/<id> (short-link → real form redirect), /admin (dashboard), /docs, /commands.

extract_offer_letter.py

PDF se details nikalta hai (pdfplumber + regex). Ek "stray space" artifact bhi handle karta hai ("P rof" → "Prof").

cloud_storage.py

PDF ko Cloudinary pe upload karke permanent URL deta hai.

db.py

Python data layer — app.py MongoDB se baat karne ke liye use karta hai.

Key concepts — regex, cron, state machine ›

Regex: text mein pattern dhoondhne ka tareeka. Dear\s+(.+?), = "Dear ke baad, comma se pehle jo hai woh pakdo" → naam nikal aata hai.

Cron: "is time pe ye chalao" scheduler. */30 17-23 * * * = 5PM-11PM, har 30 min.

State machine: user ek time pe ek hi state mein — code us state ke hisaab se react karta hai.

📱 Termux setup — proper samajh

Bot ko 24x7 chalane ke liye purane Android phone pe Termux use kiya. Sabse confusing part: Termux vs Debian.

🏠
Do "kamre" hain:
• Termux = bahar wala. Prompt $ dikhta hai.
• Debian = Termux ke andar ek Linux. Prompt # (root@localhost) dikhta hai.
Rule: Bot ka SAARA kaam Debian ke andar (#) hota hai — kyunki Chromium wahan install hui.

Kaise pehchaano tum kahan ho

  • $ dikh raha → Termux (bahar)
  • # dikh raha → Debian (andar)

Full setup (order mein)

  1. F-Droid install (browser se) → usse Termux install (Play Store wala purana hai)
  2. Termux mein: pkg install nodejs-lts git proot-distro tmux
  3. Debian install: proot-distro install debian
  4. Debian mein jao: proot-distro login debian → prompt #
  5. Debian mein: apt install -y chromium nodejs npm git nano
  6. Repo clone: git clone https://github.com/Abhinav27112005/nptel-attendance-bot.git
  7. .env file banao (MongoDB, Cloudinary, PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium, FORCE_LOCAL_AUTH=true)
  8. cd step2_whatsapp_bot && npm install --ignore-scripts
  9. node bot.js → QR aayega → doosre device se /qr khol ke phone se scan

24x7 chalao (tmux + wake-lock)

Termux band hone pe bot na mare, iske liye:

# TERMUX mein (bahar, $ prompt):
termux-wake-lock          # Android ko bolo: Termux mat maro
tmux new -s bot           # background session banao
# ab session ke andar:
proot-distro login debian # Debian mein jao
cd ~/nptel-attendance-bot/step2_whatsapp_bot
export TZ='Asia/Kolkata'
bash ~/run-bot.sh         # bot chalao (auto-restart loop)
# detach: Ctrl+B dabao, chhodo, phir D

📏 Hosting rules — phone pe chalane ke

Kal host kiya, phir band ho gaya — kyunki ye rules follow nahi hue. Inhe zaroor samjho:

1️⃣
Internet HAMESHA on rakho. Bot ko WhatsApp Web + MongoDB se lagatar connected rehna padta hai. WiFi/data band = bot disconnect. WiFi stable ho, mobile data se behtar.
2️⃣
Phone HAMESHA charging pe. 24x7 process battery jaldi khaata hai. Aur battery 0% = bot band. Charger laga ke rakho.
3️⃣
Wake-lock lagao. termux-wake-lock — bina iske Android screen off/lock pe Termux ko maar deta hai.
4️⃣
Battery optimization OFF. Settings → Apps → Termux → Battery → Unrestricted. Xiaomi/Realme/Oppo mein Autostart ON bhi karo.
5️⃣
Termux app band mat karo recent-apps se swipe karke (wake-lock ke bawajood risky). Peeche chalne do.
6️⃣
Phone WhatsApp mat unlink karo. Settings → Linked Devices mein bot ka entry rehne do.
⚠️
Bot down alert: healthchecks.io se email alert lagaya hai — bot band ho to tumhe pata chal jayega. Phir upar wale tmux steps se dobara start karo.

🚀 Deployment options (industry standard)

Ek WhatsApp bot ko 24x7 chalane ke alag-alag tareeke. Har ek ke steps niche dropdown mein:

Termux   Old Android phone (Free) ›

Best for: Zero budget. Cost ₹0.

  1. F-Droid → Termux install
  2. Debian proot install (chromium ke liye)
  3. Repo clone + npm install
  4. FORCE_LOCAL_AUTH=true (session phone disk pe)
  5. tmux + wake-lock se 24x7

Pros: free, full control. Cons: phone dedicate karna padega, battery/net ka dhyaan.

DigitalOcean   Cloud VM ($200 student credit) ›

Best for: GitHub Student Pack wale. $200 credit = ~33 months free.

  1. Student Pack se DigitalOcean $200 credit redeem
  2. Droplet banao: Ubuntu 22.04, Basic $6/mo (1GB RAM), Bangalore region
  3. SSH: ssh root@<droplet-ip>
  4. Swap file banao (2GB — Puppeteer OOM se bachne)
  5. Install: apt install -y nodejs chromium-browser git
  6. Repo clone + .env + npm install
  7. npm i -g pm2 && pm2 start bot.js --name nptel-bot
  8. pm2 startup && pm2 save (reboot auto-start)
  9. QR scan via <ip>:3000/qr

Pros: reliable, real server, no phone. Cons: card verification chahiye.

AWS EC2   Amazon cloud (Free tier 12 months) ›

Best for: AWS free tier (t2.micro/t3.micro, 12 months free, 1GB RAM).

  1. AWS account banao (card chahiye, free tier mein charge nahi)
  2. EC2 → Launch Instance → Ubuntu 22.04, t3.micro (free tier eligible)
  3. Key pair (.pem) download karo, Security Group mein SSH (port 22) allow
  4. SSH: ssh -i key.pem ubuntu@<public-ip>
  5. Swap file banao (2GB)
  6. sudo apt update && sudo apt install -y nodejs npm chromium-browser git
  7. Repo clone + .env + npm install --ignore-scripts
  8. sudo npm i -g pm2 && pm2 start bot.js --name nptel-bot && pm2 save
  9. QR scan: Security Group mein port 3000 temporarily allow → <public-ip>:3000/qr

Pros: industry standard, scalable. Cons: 12 month ke baad paid, thoda complex, billing pe nazar rakho.

Render   Web Service (Free, but limited) ›

Best for: Website/admin panel (jo abhi Render pe hai). Bot ke liye tricky.

  1. New Web Service → connect GitHub repo
  2. Root: step2_whatsapp_bot, Build: npm install, Start: node bot.js
  3. Env vars: MONGODB_URI, CLOUDINARY_URL (RemoteAuth session persist ke liye)
  4. .puppeteerrc.cjs se Chrome cache project dir mein (Render ka fix)
  5. UptimeRobot se /health ping (15-min sleep rokne ko)
⚠️
Render free tier = 512MB RAM. Puppeteer + Chromium ~400-500MB use karta hai → aksar OOM crash. Isliye humne bot ko Termux/DigitalOcean pe move kiya. Render sirf website ke liye theek hai.

🐞 Problems & fixes — poora error log

Is project mein jo bhi error aaya, uska matlab, aur kaise fix hua. Interview aur future debugging ke liye gold.

WhatsApp bot errors

Bot Bot silent tha, khud ke message pe react nahi karta ›
Matlab
message event khud ke messages pe fire nahi hota.
Fix
message_create event bhi listen kiya (jo self-messages pe fire hota hai).
Bot @lid vs @c.us — dost ka message ignore ho raha tha ›
Matlab
WhatsApp ke 2 ID formats: @c.us (phone) aur @lid (device ID). Naye accounts @lid se aate hain, aur unka phone reliably resolve nahi hota.
Fix
LINK <id> command banaya — user apni ID bata ke WhatsApp account ko profile se link karta hai. DB mein whatsapp_id save hota hai.
Bot Har message 2 baar process ho raha tha ›
Matlab
@lid messages dono message aur message_create events fire karte hain.
Fix
Message ID ka Set banaya — dobara aane wali ID skip.
Bot Reminder do baar bhej raha tha ›
Matlab
ready event reconnect pe dobara fire hota tha → do cron register.
Fix
remindersStarted flag — ek hi baar cron banao.
Bot ProtocolError: Runtime.callFunctionOn timed out ›
Matlab
Weak phone pe Chromium slow ho gaya, message bhejte waqt 180s mein jawab nahi diya → timeout crash.
Fix
protocolTimeout: 300000 (5 min), group messages (@g.us) ignore (load kam), timeout pe error-reply skip.

PDF extraction errors

PDF "P rof" instead of "Prof" — stray spaces ›
Matlab
pdfplumber ne values ke pehle character ke baad extra space daal diya (PDF generation artifact).
Fix
clean_stray() — index-1 pe space ho to hata do. ID/dates ke liye saare space hata do.
PDF Date mein agli line ka digit aa raha tha ›
Matlab
Regex [\d\s-]+ mein \s newline bhi match karta tha.
Fix
[\d -]+ use kiya (sirf space aur hyphen, newline nahi).
Form Dropdown/date/time fill nahi ho raha tha (purana Playwright approach) ›
Matlab
Google Forms ke dropdown custom divs hain; date native input hai; time 2 alag boxes.
Fix
Dropdown = listbox click + data-value; date = native input[type=date] "YYYY-MM-DD"; time = "Hour"/"Minute" boxes. (Baad mein pura pre-filled URL approach pe switch kiya.)

Cloud / deployment errors

MongoDB SSL handshake failed ›
Matlab
Atlas ka IP access list expire ho gaya tha (temporary "allow anywhere").
Fix
Network Access mein 0.0.0.0/0 permanent add kiya.
Render Port scan timeout — deploy fail ›
Matlab
Render $PORT pe traffic bhejta hai, par app default port pe sun rahi thi.
Fix
Start command: gunicorn app:app --bind 0.0.0.0:$PORT
Render Could not find Chrome (Puppeteer) ›
Matlab
Chrome build phase mein download hua par runtime tak persist nahi hua (Render cache alag hai).
Fix
.puppeteerrc.cjs se cache directory ko project source ke andar rakha (jo runtime tak survive karta).
Cloudinary PDF upload silently skip ›
Matlab
Render pe CLOUDINARY_URL env var set nahi tha.
Fix
Render dashboard → Environment mein env var add kiya. (Debug: local pe test kiya — chala → matlab env issue.)

Termux / proot errors

Ubuntu chromium snap error ›
Matlab
Ubuntu ka chromium ab snap-only hai, aur snap proot mein nahi chalta.
Fix
Ubuntu chhod ke Debian use kiya — usme asli (non-snap) chromium hai.
npm ENOENT rename — cache corrupt ›
Matlab
proot ka filesystem rename operation mein dikkat karta hai, npm cache corrupt ho jata hai.
Fix
rm -rf ~/.npm/_cacache + npm install --maxsockets 1 (ek-ek file, no parallel).
npm cosmiconfig "Missing loader for extension package.json" ›
Matlab
Fresh install pe cosmiconfig v9 aa gaya, jo puppeteer ke saath toot jata hai (v9 ne package.json loader hata diya).
Fix
package.json mein "overrides": { "cosmiconfig": "8.3.6" } — purana compatible version force.
Session QR loop — restart pe dobara QR maang raha ›
Matlab
Render pe filesystem ephemeral — session udd jati. Termux pe RemoteAuth ka Mongo-zip backup fail ho raha tha.
Fix
Termux (persistent disk) pe FORCE_LOCAL_AUTH=true — session phone disk pe permanent.
Time Debian galat timezone (3 AM dikha raha tha) ›
Fix
ln -sf /usr/share/zoneinfo/Asia/Kolkata /etc/localtime + export TZ='Asia/Kolkata' run-bot.sh mein.
Termux Bot band ho gaya Termux close karne pe ›
Matlab
Bina wake-lock, Android ne Termux ko screen-off pe maar diya.
Fix
termux-wake-lock + battery optimization OFF + tmux at Termux level.
