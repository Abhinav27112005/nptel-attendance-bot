NPTEL Attendance Bot

A WhatsApp bot that fills your daily NPTEL internship attendance in seconds.

Ye docs bilkul simple bhasa mein hai — maano tumhe kuch nahi aata. Har cheez seedhe samjhayi gayi hai, diagrams ke saath.

📌 Overview

Problem: NPTEL internship mein roz ek Google Form bharni padti hai — 12 fields, jinme sirf "aaj kya kaam kiya" aur time badalta hai, baaki sab same rehta hai. Boring aur repetitive.

Solution: WhatsApp bot ko bhejo WORK: aaj jo kaam kiya → woh ek bhara-bharaya form link wapas bhejta hai. Tap karke Submit dabao — done.

✅
2 minute ka manual kaam → 10 second ka WhatsApp message. 10 doston ke liye ek saath.

🧠 Key concepts — pehle ye samjho

Project samajhne se pehle kuch buniyaadi cheezein. Har ek ek line mein:

Node.js ›

JavaScript ko browser ke bahar chalane wala engine. Normally JS website mein chalta hai; Node.js se woh ek normal program ki tarah computer/phone/server pe chalta hai. Humara bot Node.js program hai.

WhatsApp Web ›

WhatsApp ka website version (web.whatsapp.com). Phone se QR scan karke browser mein WhatsApp use karte ho. Humara bot isi WhatsApp Web ko automate karta hai.

Headless browser ›

Ek browser jo bina window dikhaye (invisible) chalta hai. Screen pe kuch nahi dikhta, par andar-andar sab kaam hota hai. Server pe monitor nahi hota, isliye headless zaroori hai.

API ›

Do programs ke beech baat karne ka tareeka. Jaise restaurant mein waiter (API) tumhare aur kitchen ke beech order pahunchata hai. Cloudinary API, MongoDB — sab APIs se baat karte hain.

Database (MongoDB) ›

Data ko permanently store karne ki jagah. MongoDB "document" database hai — data JSON jaisा dikhta hai (naam, ID, mobile...). Excel sheet ka smart version samjho.

Environment variable (.env) ›

Secret settings (password, API keys) jo code mein nahi likhte. Ek alag .env file mein rakhte hain jo GitHub pe nahi jaati. Code un secrets ko process.env se padhta hai.

Cron job ›

"Is time pe ye chalao" wala alarm clock, code ke liye. Reminder system cron use karta hai — 5PM-11PM har 30 min.

Regex ›

Text mein pattern dhoondhne ka tareeka. Dear\s+(.+?), = "Dear ke baad comma se pehle jo hai woh pakdo" → naam. PDF se details nikalne mein use hua.

🎭 What is Puppeteer? (important)

Ye samajhna zaroori hai kyunki humari aadhi problems isi se aayi.

Puppeteer ek Node.js library hai jo Chrome browser ko code se control karti hai — jaise ek robot ke haath jo keyboard-mouse chalate hain. Tum code mein likhte ho "ye button dabao, ye type karo", Puppeteer Chrome mein woh karta hai.

Bot → Puppeteer → chhupa hua Chromium → WhatsApp Web. Ye poori chain phone/server pe chalti hai.

Puppeteer ki wajah se aayi problems

  • RAM khaata hai — Chromium bhaari hai (~400MB). Render 512MB pe OOM crash hota tha.
  • "Could not find Chrome" — Puppeteer ko Chrome download karna padta hai; cloud pe path issue aaya.
  • protocolTimeout — weak phone pe Chromium slow ho jaye to Puppeteer ka command time out ho jata hai.
  • Chromium install — Termux/Debian pe alag se chromium install karna pada.
🎯
Yahi wajah thi ki humne form bharne ke liye Puppeteer/Playwright chhoda aur pre-filled link pe switch kiya. WhatsApp ke liye Puppeteer abhi bhi zaroori hai (whatsapp-web.js internally use karta hai), par form ke liye nahi.

📂 Code explained

step2_whatsapp_bot/ — the bot ›

bot.js — dil. Events sunta hai, state machine (IDLE/AWAITING_CONFIRM), command parsing (WORK:/YES/LINK...), auth strategy (session save), health server (/qr, /health).

prefill.js — Google Form ka bhara-bharaya URL banata hai (entry IDs ke saath).

db.js — MongoDB ya local files se users laata/save karta hai.

reminder.js — cron scheduler (5-11PM reminders).

step4_web_onboarding/ — the website ›

app.py — Flask routes: / registration, /register, /r/<id> short-link redirect, /admin, /docs, /commands.

extract_offer_letter.py — PDF se details (pdfplumber+regex).

cloud_storage.py — PDF Cloudinary pe upload.

db.py — Python data layer.

📏 Hosting rules — phone pe chalane ke

1️⃣
Internet HAMESHA on. WhatsApp Web + MongoDB se lagatar connected rehna padta. WiFi stable rakho.
2️⃣
Phone HAMESHA charging pe. 24x7 process battery khaata hai.
3️⃣
Wake-lock: termux-wake-lock — bina iske Android screen-off pe Termux maar deta hai.
4️⃣
Battery optimization OFF: Settings → Apps → Termux → Unrestricted. Xiaomi/Realme/Oppo mein Autostart ON.
5️⃣
Termux swipe-close mat karo. Background mein chalne do.
6️⃣
Phone WhatsApp se bot unlink mat karo. Linked Devices mein rehne do.
⚠️
healthchecks.io se down-alert lagaya hai — bot band ho to email aa jayega.

🚀 Deployment — full step-by-step

Har platform ke poore steps dropdown mein. Copy-paste ready.

FREE  Termux  Old Android phone ›

Phase 1 — F-Droid & Termux

  1. Phone browser: f-droid.org → Download F-Droid APK → install (unknown sources allow karo)
  2. F-Droid mein search: Termux → install. Saath mein Termux:Boot bhi.

Phase 2 — Termux base setup

termux-setup-storage        # storage permission (Allow)
pkg update -y && pkg upgrade -y
pkg install -y nodejs-lts git proot-distro tmux

Phase 3 — Debian install (chromium ke liye)

proot-distro install debian
proot-distro login debian    # ab prompt # ho jayega

Phase 4 — Debian ke andar (# prompt)

apt update
apt install -y chromium nodejs npm git nano
chromium --version           # confirm kare
which chromium               # /usr/bin/chromium (note karo)

Phase 5 — Repo + config

cd ~
git clone https://github.com/Abhinav27112005/nptel-attendance-bot.git
cd nptel-attendance-bot
nano .env

.env mein daalo:

MONGODB_URI=your-mongodb-string
CLOUDINARY_URL=your-cloudinary-url
ADMIN_PASSWORD=strong-password
PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium
FORCE_LOCAL_AUTH=true

Phase 6 — Install & first run

cd step2_whatsapp_bot
npm install --ignore-scripts
node bot.js                  # QR aayega

QR scan: doosre device pe http://<phone-ip>:3000/qr khol ke phone se scan karo. Phir Ctrl+C.

Phase 7 — 24x7 (tmux + wake-lock)

exit                         # Debian se bahar, ab Termux ($)
termux-wake-lock
tmux new -s bot
proot-distro login debian
cd ~/nptel-attendance-bot/step2_whatsapp_bot
export TZ='Asia/Kolkata'
bash ~/run-bot.sh
# detach: Ctrl+B dabao, chhodo, phir D

Phase 8 — Battery

Settings → Apps → Termux → Battery → Unrestricted. Autostart ON (Xiaomi/Realme/Oppo). Phone charging pe rakho.

$200 CREDIT  DigitalOcean  Cloud VM — full 20 steps ›

Phase 1 — Credit & Droplet

  1. education.github.com/pack → DigitalOcean → $200 credit redeem (GitHub account connect)
  2. DO Dashboard → Create → Droplets
  3. Region: Bangalore (BLR1)
  4. Image: Ubuntu 22.04 LTS

  6. Authentication: Password → strong password set karo (note karo)
  7. Create Droplet → 60 sec mein ban jayega → IP address note karo

Phase 2 — SSH connect (laptop se)

  1. PowerShell/terminal: ssh root@<DROPLET_IP>
  2. "Are you sure?" → yes → password daalo (typing nahi dikhega, normal hai)
  3. Success: root@droplet:~# dikhega

Phase 3 — Server setup

# 11. System update
apt update && apt upgrade -y

# 12. Swap file (2GB) — Puppeteer OOM se bachne ko
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' | tee -a /etc/fstab

# 13. Node.js LTS
curl -fsSL https://deb.nodesource.com/setup_lts.x | bash -
apt install -y nodejs

# 14. Chromium + Puppeteer dependencies
apt install -y chromium-browser git

# 15. Verify
node --version
which chromium-browser        # /usr/bin/chromium-browser

Phase 4 — Deploy bot

# 16. Clone + env
cd /root
git clone https://github.com/Abhinav27112005/nptel-attendance-bot.git
cd nptel-attendance-bot
nano .env
# daalo: MONGODB_URI, CLOUDINARY_URL, ADMIN_PASSWORD,
# PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium-browser, FORCE_LOCAL_AUTH=true

# 17. Install
cd step2_whatsapp_bot
npm install --ignore-scripts

Phase 5 — PM2 (24x7 + auto-restart)

# 18. PM2 install & start
npm install -g pm2
pm2 start bot.js --name nptel-bot

# 19. Boot pe auto-start
pm2 startup                   # jo line bole use run karo
pm2 save

# 20. QR scan: browser mein http://<DROPLET_IP>:3000/qr
pm2 logs nptel-bot            # logs dekho, "ready" confirm

Update code: cd ~/nptel-attendance-bot && git pull && cd step2_whatsapp_bot && pm2 restart nptel-bot

FREE*  Render  Web Service (website ke liye best) ›

Website/admin Render pe hi hai. Bot ke liye 512MB tight hai (OOM) — isliye bot Termux/VPS pe.

Website deploy (jo abhi hai)

  1. Render → New → Web Service → connect repo
  2. Root Directory: step4_web_onboarding
  3. Build: pip install -r requirements.txt
  4. Start: gunicorn app:app --bind 0.0.0.0:$PORT
  5. Env vars: MONGODB_URI, CLOUDINARY_URL, ADMIN_PASSWORD, BOT_WHATSAPP_NUMBER
  6. Create → live URL milega

Agar bot bhi Render pe (advanced)

  1. Root: step2_whatsapp_bot, Start: node bot.js
  2. .puppeteerrc.cjs cache fix (already repo mein)
  3. MONGODB_URI set (RemoteAuth session persist) — FORCE_LOCAL_AUTH mat set karo
  4. UptimeRobot se /health har 5 min ping (sleep rokne ko)
  5. QR: <service>.onrender.com/qr
